# Xeve Homebrew tap

Homebrew casks for apps by [Xeve](https://xeve.io).

```sh
brew trust xeveio/tap        # Homebrew 7+ asks you to trust third-party taps once
brew install --cask xeveio/tap/gobbl
```

| Cask | App |
|---|---|
| `gobbl` | [Gobbl](https://gobbl.xeve.io): the free, open-source notch app for Mac, with a pet |

Gobbl updates itself (Sparkle), so `brew upgrade` isn't needed; the cask is bumped with each release.
